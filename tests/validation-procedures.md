# Bounded validation procedures

Historical scripts that treated command errors as defense success are excluded. In an authorized separate lab, record actual hostname, source address, route, UTC time, exact command/revision and output. Use the fixed S 04 TCP matrix and compare states; network timeout alone does not identify which policy blocked traffic. Keep a positive allowed-flow check.

For RBAC, use fresh employee/admin browser sessions and record employee 200/admin 403 plus authorized-admin 200. A token endpoint 400/401 alone does not prove MFA. For DB restrictions, use the application role, preserve required reads, and use no-row/rolled-back denial probes; distinguish privilege errors from connection/service errors. Do not execute destructive DROP tests on a live dataset. For response, label injected events and separately verify add/delete traces and source attribution if reopening that scope.

These procedures are not execution evidence. No lab restart or new campaign is required by the scope freeze.
